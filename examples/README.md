# Examples — أمثلة حية كاملة

> **مشاريع نموذجية مكتملة** توضح المهارة في العمل.

## المتاح

| المثال | النوع | المدة | الإصدار | الوصف |
|---|---|---|---|---|
| `coffee-short.md` | قصة قصيرة | 60s | v1.x | مثال v1.x كلاسيكي |
| `energy-drink-ad.md` | إعلان منتج | 30s | **v2.0** | مثال v2.0 الكامل (5 Output Packages) |

## كيف تستخدم

1. **اقرأ** المثال كاملاً
2. **لاحظ** كيف تُطبَّق المبادئ (10 طبقات A-J، Frame Chain، Quality Gates)
3. **استخدم** نفس البنية لمشروعك

## المساهمة

عند إنشاء مشروع جديد ناجح، شاركه كمثال:
- اتبع نفس البنية (Concept → 5 Packages)
- وثق Quality Gates
- شارك في PR
